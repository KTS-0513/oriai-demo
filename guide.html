おりあいを、学校で使えるようにする手引き

スプレッドシートの中にアプリを入れて、生徒に配る URL を作ります。プログラムの知識はいりません。やることは、コピーと貼り付けとボタン操作です。

かかる時間約10分
使うものパソコン（Chromebook も可）
アカウント学校の Google アカウント

個人の Gmail では作らないでください。だれが書いたかを確かめられず、生徒が使えません。

ステップ 1

スプレッドシートを作る

  1. 新しいスプレッドシートを開く（別のタブで開きます）。
  2. 左上の 無題のスプレッドシート を押して、おりあい と入力します。
  3. 右上の丸いアイコンを押して、学校のアカウントになっているか確かめます。

違うアカウントのときは、学校のアカウントに切りかえてから、もう一度開きます。

ステップ 2

Apps Script を開く

  1. シートの上のメニューから 拡張機能 を押します。
  2. Apps Script を押します。プログラムを書く画面が、新しいタブで開きます。

Apps Script：スプレッドシートの裏側にプログラムを置く場所です。シートとセットで保存されます。

ステップ 3

1つ目のプログラムを貼る

  1. Apps Script の画面で、最初から書いてある文字の中を1回クリックします。
  2. Ctrl＋A で全部選んで、Delete で消します（Mac は ⌘＋A）。
  3. Ctrl＋V で貼り付けます（Mac は ⌘＋V）。
  4. Ctrl＋S で保存します（Mac は ⌘＋S）。

左のファイルの名前は コード.gs のままで大丈夫です。

ステップ 4

2つ目のプログラムを貼る

  1. 左の ファイル の右にある ＋ を押して、HTML を選びます。
  2. 名前を index と入力して、Enter を押します。.html は入力しません（自動で付きます）。
  1. 開いた index.html の文字の中をクリックして、全部選んで消します。
  2. 貼り付けて、保存します。
  3. いちばん下までスクロールして、最後が </html> で終わっていれば、全部貼れています。
ステップ 5

初期セットアップをする

  1. スプレッドシートのタブに戻って、ページを再読み込みします（F5、または Ctrl＋R）。
  2. 10秒ほど待つと、メニューの右に おりあい が出ます。押して 初期セットアップ を選びます。
  3. 承認が必要です と出たら、OK（または 続行）を押し、学校のアカウントを選んで、許可 を押します。
  4. 許可のあと、もう一度 おりあい → 初期セットアップ を押します。
  5. 先生のパスワード の欄が出ます。先生の画面に入るためのパスワードを6文字以上で決めて入力し、OK を押します。
  6. パスワードを保存しました と出たら完了です。画面の下にシートが4枚できています。

パスワードは、生徒が思いつかないものにしてください。このパスワードで、生徒全員の記入が見られます。先生どうしで共有するものなので、ふだん使っている自分のパスワードは使わないでください。

「Google で確認されていません」と出たときは、下の「困ったとき」を見てください。

ステップ 6

ウェブアプリとして公開する

  1. Apps Script のタブに戻り、右上の青い デプロイ を押して、新しいデプロイ を選びます。
  2. 種類の選択 の横の歯車を押して、ウェブアプリ を選びます。
  3. 下の図のとおりに、2か所を設定します。
  4. デプロイ を押します。アクセスを承認 と出たら、ステップ5と同じように許可します。
  5. ウェブアプリ の下に出た URL を コピー して、完了 を押します。

「全員」や「自分のみ」は選びません。「全員」だと学校の外からも開け、「自分のみ」だと生徒が開けません。

デプロイ：作ったアプリを公開して、開くための URL を作ることです。

ステップ 7

配る URL を作る

ステップ6でコピーした URL を、下の欄に貼ってください。URL はこのページの外には送られません。

配る URLhttps://script.google.com/a/macros/（学校）/s/（ID）/exec

いま出ているのは見本です。貼ると、本物の URL に変わります。

この URL を Classroom などで配ります。生徒も先生も同じ URL です。先生は、開いた画面の右上にある 先生の方はこちら を押して、パスワードで入ります。

ステップ 8

生徒に配る前に確かめる

生徒役として、自分とは別の学校アカウントが必要です。同僚の先生に頼むか、検証用のアカウントを使ってください。

  1. 生徒役のアカウントで生徒用の URL を開き、組・番号・名前を入れて課題を書きます。右上に 保存しました と出ます。
  2. スプレッドシートの Devs を開きます。1行増えていて、組の「1-1」が日付に変わっていなければ正常です。
  3. 最後まで書いて 課題を提出する を押すと、案内が出ます。案を3つにして × を押すと、消してよいかの確認が出ます。
  4. 同じ URL を開き、右上の 先生の方はこちら を押して、パスワードを入れます。さっき書いた生徒が一覧に出ます。
  5. わざと違うパスワードを入れます。パスワードが違います と出て、入れなければ正常です。
  6. 授業で使う前に、クラスの人数で一度に開いて、遅くならないか・保存が失敗しないかを見ます。

困ったとき

「Google で確認されていません」と出た

自分で貼ったプログラムを初めて動かすときに出ることがあります。詳細 を押して、下に出る （プロジェクト名）に移動 を押し、許可 を押します。

「拡張機能」や「Apps Script」が見つからない・開けない

学校の管理者が Apps Script を止めていることがあります。学校の Google の管理担当の方に確かめてください。

メニューに「おりあい」が出ない

シートを再読み込みして、10秒ほど待ちます。それでも出ないときは、ステップ3の貼り付けと保存ができているかを見ます。

先生の画面に入れない・パスワードを忘れた

シートのメニュー おりあい → 先生のパスワードを変える で、新しいパスワードを決めます。忘れたパスワードを調べる方法はありません。

5回続けて間違えると、そのアカウントは10分間試せなくなります。10分待つか、別のアカウントで入ります。

「アカウントを確認できませんでした」と出た

学校のアカウントで開いているかを確かめます。複数のアカウントでログインしているときは、シークレットウィンドウで開き、学校のアカウントだけでログインします。

生徒が「アクセスが拒否されました」で開けない

ステップ6の「アクセスできるユーザー」が「（学校のドメイン）内の全員」になっているかを見ます。生徒のアカウントが、作った人と同じドメインかも確かめます。

アドレスバーから写した URL は、/u/1/ が混ざって開けないことがあります。ステップ7で作った URL を配ります。

画面に「うまくいきませんでした」と出た

左下の ログ を押すと、くわしい内容が出ます。全文を控えて、作った人に伝えてください。

プログラムを新しくしたとき

  1. Apps Script に新しい中身を貼り直して、保存します。
  2. 右上の デプロイ から デプロイを管理 を選びます。
  3. 右上の鉛筆を押して、バージョン を 新バージョン にし、デプロイ を押します。

「新しいデプロイ」は選びません。URL が変わって、配った URL が使えなくなります。

画面の言葉や配置は、Google の更新で少し変わることがあります。図は説明のために単純にしたものです。
